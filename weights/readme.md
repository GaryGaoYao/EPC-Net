# EPC-Net Model Weights

The trained EPC-Net model weights are **not included in this repository**.

## Requesting Access

To request access:

1. Open the following form in the [`weights`](./) folder:  
   [`Model Weight Access Request and Research-Use Statement.pdf`](./Model%20Weight%20Access%20Request%20and%20Research-Use%20Statement.pdf)
2. Complete all required fields.
3. Sign the form.
4. Send the completed and signed PDF to the project team using one of the email addresses: yao.gao@kuleuven.be.
